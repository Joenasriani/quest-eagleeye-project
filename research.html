Meta Quest to EagleEye: Tactical XR Concept Study

An independent concept study exploring how Meta Quest 3, thermal sensing, LoRa/Meshtastic concepts, gaze interaction and consumer hardware can be combined into an experimental wearable spatial interface.

Project document · GitHub repository · Quest Research collection · Author record

Status: research for a proposed mixed-reality prototype. The project document describes a proposed architecture and test plan; it does not provide records establishing a completed integrated build or measured performance. It does not claim functional equivalence with specialized military systems.

Field classification

  • Primary field: mixed-reality systems integration / wearable spatial computing
  • Platform: Meta Quest 3 and Android-based mixed reality
  • Sensor field: thermal / LWIR imaging
  • Communications field: LoRa / Meshtastic concepts
  • Interaction field: gaze-driven XR and spatial HCI
  • Systems field: wearable USB-C power/data and hardware integration
  • Adjacent fields: robotics operator interfaces, field visualization, immersive training and wearable computing

Research question

Which mixed-reality situational-awareness functions can be prototyped with consumer off-the-shelf hardware, and what integration trade-offs appear when sensing, communications, power and immersive display are combined in a wearable system?

Technical frame

The concept joins Meta Quest 3 mixed reality, external thermal sensing, LoRa/Meshtastic-style communications, USB-C power/data integration and gaze-driven interaction. This makes it a systems-integration problem spanning hardware, XR, networking, sensing and HCI.

Evidence boundary

The component budget is a historical planning estimate without supplier quotations or purchase records. Latency, range, runtime and integrated operation require documented measurements. Illustrative code and assembly descriptions do not establish a validated build. The work makes no certification or operational safety claim.
